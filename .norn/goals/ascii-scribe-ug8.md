# 從 figlet 輸出自動推算筆順，任意英數符號 × 線條型字型都能逐筆寫出、倒序擦掉並循環的 Web Component，並在 yPin9.github.io 以 jsDelivr 釘版本上線

**原本的要求**：網頁動態的 ASCII 動畫：ASCII 大字打字、backspace 重打，一筆一筆出來

## 提升（高度／深度／廣度）
高度：讓 λ66 首頁有記憶點並可重用；深度：自動推算筆順而非手寫，任意文字與字型通用；廣度：借用書法筆順與圖形走訪（連通元件、路徑追蹤）

## 成功的定義
- 隨機英數符號字串在 ≥5 種線條型 figlet 字型下逐筆畫出，無寫死筆順
- 最終畫面與 figlet.textSync() 逐字相同
- 同一筆內相鄰比例 ≥ 90%
- 倒序刪除、多句循環、速度與停頓可設定
- reduced-motion 直接顯示、螢幕閱讀器讀原文、360px 不溢出
- 使用者親眼確認看起來像在寫字
- yPin9.github.io 以 jsDelivr 釘版本引用並部署成功

## 用什麼證據證明
自動測試使用程式隨機產生的字串做最終畫面比對與相鄰比例；正式 Hugo 建置 + GitHub Pages 桌機/手機實測；使用者人工確認
